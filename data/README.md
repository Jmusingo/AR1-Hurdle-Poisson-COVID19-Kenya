Data Source and Documentation

Data Source

The data used in this research were obtained from the World Health Organization (WHO) COVID-19 Dashboard.

Source: WHO COVID-19 Dashboard – Data

The project uses a Kenya-specific extract of daily COVID-19 deaths reported to WHO.

Dataset Description

The analysis dataset contains two variables:

date: Date of reporting to WHO.

deaths: Number of newly reported COVID-19 deaths in Kenya.

The dataset contains 902 daily observations covering 1 March 2020 to 19 August 2022.

Data Preparation

The original WHO data were extracted and prepared for statistical analysis. The resulting dataset was used for exploratory data analysis, AR(1) Hurdle Poisson model estimation, model diagnostics, simulation studies and forecasting.
