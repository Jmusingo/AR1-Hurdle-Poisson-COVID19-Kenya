AR(1) Hurdle Poisson Model for COVID-19 Mortality in Kenya

Project Overview

This project applies a First-Order Autoregressive Hurdle Poisson (AR(1) HP) model to daily COVID-19 mortality data in Kenya. The study addresses two important characteristics of the data: excess zero observations and temporal autocorrelation.

The analysis was conducted as part of an MSc Applied Statistics research project at Maseno University.

Research Objectives

The main objective was to apply a First-Order Autoregressive Hurdle Poisson (AR(1) HP) model to analyse and forecast daily COVID-19 mortality in Kenya, while accounting for excess zeros and temporal dependence in the data.

The specific objectives were to:
To examine the distributional characteristics of daily COVID-19 mortality data in Kenya, with emphasis on excess zeros and temporal dependence.
To formulate the AR(1) Hurdle Poisson model for excess-zero count time series data.
To estimate the parameters of the proposed AR(1) Hurdle Poisson model using maximum likelihood estimation.
To assess the goodness-of-fit and predictive performance of the model.
To evaluate the short-term forecasting performance of the model in predicting daily COVID-19 mortality in Kenya.

Methodology

The analysis involved:
Data preparation and exploratory data analysis.
Examination of temporal dependence using ACF and PACF plots.
Formulation of the AR(1) Hurdle Poisson model.
Parameter estimation using Maximum Likelihood Estimation.
Model diagnostics and goodness-of-fit assessment.
Monte Carlo simulation to assess parameter estimation performance.
Short-term mortality forecasting and forecast evaluation.

Tools and Technologies

R – statistical computing and modelling.
Statistical methods – time-series analysis, count-data modelling, maximum likelihood estimation and simulation.
Visualisation – exploratory plots, diagnostic plots and forecast comparisons.

Key Findings
The analysis demonstrated the application of a hurdle-based count-data model to COVID-19 mortality observations containing excess zeros and temporal dependence.
The model was evaluated through parameter estimation, simulation, diagnostic assessment and short-term forecasting.
